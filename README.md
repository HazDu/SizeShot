# SizeShot

**[▶ Open SizeShot](https://sizeshot.hazdu.de)**

SizeShot lets you add measurements and notes to photos and screenshots right in your browser. Load an image, draw dimension lines, callouts, arrows, angles and highlights on it, then export the result as an image or copy it straight to the clipboard. There's nothing to install or sign up for, and your images stay on your device.

## How to use

1. Open SizeShot and load an image: drop it onto the page, paste it with <kbd>Ctrl</kbd>+<kbd>V</kbd>, or click **Choose image**.
2. Pick a tool from the left toolbar and draw on the image.
3. Adjust color, line width, labels and borders in the panel on the right.
4. Click **Export PNG** to download the result, or **Copy** to paste it somewhere else.
5. Want to keep editing later? Click **Save** to store a project file, and reopen it with **Open**.

## Features

- **Annotation tools:** dimension line, callout (label with arrow), text, arrow, angle, box, circle and numbered marker
- **Styling:** colors, line width, dashed lines, fill, label and border options per shape
- **Editing:** select, move, duplicate, bring to front, delete, undo/redo
- **Zoom & pan:** zoom buttons, mouse wheel, fit to screen, space + drag to pan
- **Export:** download as PNG, JPG or WebP, or copy the annotated image to the clipboard
- **Projects:** save your work as a `.json` project and reopen it later to keep editing

| <kbd>C</kbd> | Callout |
| <kbd>T</kbd> | Text |
| <kbd>A</kbd> | Arrow |
| <kbd>G</kbd> | Angle |
| <kbd>R</kbd> | Box |

| <kbd>Space</kbd> + drag | Pan |

| <kbd>Ctrl</kbd>+<kbd>D</kbd> | Duplicate selected shape |
| <kbd>Ctrl</kbd>+<kbd>S</kbd> | Save project |
